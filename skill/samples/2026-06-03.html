今天这期有三条主线最清楚：一是 AI 安全从“防提示词注入”往真实世界延伸，谷歌做防深伪来电、Anthropic 扩大关键基础设施安全计划，都是把风险治理做实。二是个人 agent 和多代理工作台进入新阶段，微软 Scout 与 Devin Desktop 都在抢“长期陪跑型助手”的入口。三是视频、网页智能体和 agent 基建继续加速开源，Bernini-R、OpenWebRL、Headroom 等项目都不是概念展示，而是已经能被工程团队拿来试的基础能力。监管层也开始下场，特朗普的行政令说明 frontier model 的发布前安全评估，正在被当成一件正式制度问题来处理。

🔥 今日焦点

焦点

谷歌上线防深伪来电检测功能

谷歌宣布在 Phone by Google 中推出 fake call detection，本月先从 Pixel 开始向 Android 12 及以上设备推送，并计划全球上线。这项功能直接针对 AI 语音克隆冒充诈骗，默认开启，在后台通过设备间的“数字握手”确认来电是否真的来自联系人手机。若号码被伪造、却缺失静默确认信号，系统就会对用户发出风险提示。随着诈骗者从陌生号骚扰转向“冒充家人和老板”骗钱，这类端侧校验比传统垃圾电话识别更有现实价值。

AI锐评：AI 骗局已经从“看上去像”进化到“听上去也像”，谷歌这次终于把防线往系统层挪了一步。

🔗 https://techcrunch.com/2026/06/02/google-rolls-out-fake-call-detection-to-protect-against-ai-deepfake-impersonation-scams/

🚀 产品发布

微软发布个人智能助手 Scout

微软发布 Scout，定位是把 OpenClaw 式的高自由度个人 agent 带进 Microsoft 365 生态。TechCrunch 披露它基于 OpenClaw framework，强调 always-on、持续记忆、可被用户长期反馈调教，用户甚至可以给自己的 Scout 命名并沉淀技能与工作习惯。它目前通过 Frontier program 提前开放，核心卖点不是一次性回答问题，而是让助手随着使用不断贴近个人工作方式。对微软来说，这意味着它开始从“在 Office 里塞 AI 按钮”，走向“给知识工作者配一个持久身份的 agent”。

AI锐评：微软终于开始争夺“个人 agent 操作系统”，而不只是 Copilot 侧边栏。

🔗 https://techcrunch.com/2026/06/02/microsoft-launches-scout-an-openclaw-inspired-personal-assistant/

Windsurf 更名为 Devin Desktop

Cognition 把 Windsurf 升级为 Devin Desktop，核心变化不是简单换壳，而是把“Agent Command Center”推到正中央。官方博客显示，新版本把本地与云端代理统一进单一 Kanban 视图，并加入 Spaces 共享上下文，把 session、PR、文件和上下文打成一组。更关键的是它首发支持 ACP（Agent Client Protocol），上线就兼容 Codex、Claude Agent、OpenCode 以及团队自建代理。对多代理协作团队来说，这更像一个 agent 调度台，而不是单一 IDE 插件。

AI锐评：谁能先把多代理协作做成“默认工作台”，谁就更有机会吃下下一轮开发者入口。

🔗 https://devin.ai/blog/windsurf-is-now-devin-desktop

字节跳动开源多模态视频模型 Bernini-R

字节跳动在 Hugging Face 开源 Bernini Renderer（Bernini-R）的推理代码和模型权重，继续把视频生成能力往“可复现、可部署”方向推进。模型卡显示，Bernini 采用 MLLM 语义规划器加 DiT 渲染器的统一架构，同时覆盖视频生成与视频编辑两类任务，并声称在编辑任务上已达到一线闭源商用模型水准。项目文档还给出了较明确的工程环境，建议使用 H100、H800、H200 等 Hopper GPU，并固定到 PyTorch 2.5.1+cu124 等版本。相比只放 demo，这次更像一份可以让研究者和工程团队直接上手复现的交付。

AI锐评：视频模型开源已经不再满足于“能跑”，而是开始卷到“能不能被别人复现成生产力”。

🔗 https://huggingface.co/ByteDance/Bernini-R

英伟达发布物理世界大模型

英伟达在官方社媒发布物理世界大模型，定位是让机器人先在虚拟环境中学习动作预测和物理反馈，再把策略迁移到真实世界。现有公开信息还不算完整，但聚合页给出的重点是混合架构、高精度模拟，以及面向机器人训练的世界建模能力。它的意义不在于再做一个“会看会说”的模型，而是把感知、预测和控制前移到统一模拟框架里。对具身智能团队来说，这类模型一旦成熟，会明显降低真实设备试错成本。

AI锐评：芯片公司开始卷世界模型，说明卖算力的下一步已经是卖“可训练的物理世界”。

🔗 https://x.com/NVIDIAAI/status/2061870464549466565

💡 前沿研究

OpenWebRL 开源网页智能体强化学习框架

OpenWebRL 试图把视觉网页智能体的训练，从昂贵的人工示范数据，转到真实网站上的在线多轮强化学习。论文给出的完整链路包括 live-browser 基础设施、监督式冷启动、多模态上下文管理、轨迹级成功判定和多轮策略优化。作者用 0.4K 条初始化轨迹和 2.2K 个开放式 RL 任务训练出 OpenWebRL-4B，在 Online-Mind2Web 上做到 67.0% 成功率，在 DeepShop 上做到 64.0%。这说明开放模型在真实网页操作上的差距，开始能靠训练框架而不是只靠更大的底模去追。

AI锐评：网页 agent 的瓶颈越来越像数据和训练制度问题，而不是单纯再堆参数。

🔗 https://arxiv.org/abs/2606.02031

研究团队提出防表征崩溃正则化方法

UR-JEPA 针对 JEPA 训练里最头疼的 representation collapse 问题，提出了基于 uniform rectifiability 的新正则化路线，而不是继续把嵌入空间往各向同性高斯目标上硬拉。论文数据显示，在 Inet10 上，UR-JEPA 取得 0.9141±0.0014 的结果，相比 LeJEPA 的 SIGReg 方案提升 0.83 个百分点，同时把 seed 标准差压低约 30%。在 EuroSAT 上，它还能以 25 倍更小的 backbone，打到 96.0% 到 96.1% 的同档精度。对自监督表示学习来说，这种“更稳而不只是更高”的改进，往往比单点刷榜更值钱。

AI锐评：很多论文只会把分数抬高一点点，UR-JEPA 更难得的地方是把训练稳定性也一起抬上来了。

🔗 https://arxiv.org/abs/2606.01443

新视频生成框架用低秩潜变量压缩显存

VideoMLA 把多头潜变量注意力（MLA）第一次系统性搬进视频扩散模型，瞄准的是长时视频生成里最贵的 KV cache。论文页给出的核心数字是：它用共享的低秩内容潜变量和解耦的 3D-RoPE positional key，把每个 token 的缓存内存压缩了 92.7%。更重要的是，作者强调这不是简单套用语言模型经验，而是在视频扩散场景里重新验证了低秩表示何时有效。对分钟级自回归视频生成来说，谁能先把缓存压下来，谁就更接近可商用。

AI锐评：视频生成继续卷效果已经很难拉开差距，真正决定成本曲线的开始变成缓存和推理架构。

🔗 https://huggingface.co/papers/2605.30351

📜 政策 & 监管

特朗普签署 AI 审核行政令

特朗普签署行政令，要求美国联邦机构制定一套“自愿框架”，让 AI 公司在模型正式发布前，可选择与政府共享 frontier model 信息。The Verge 报道称，这套机制重点评估模型的高级网络攻击能力，并给愿意配合的企业提供一定保密保护，同时要求政府提前准备面向关键基础设施的 AI 网络防御。它不是强制审批制度，但已经明确释放出一个信号：前沿模型的安全评估，正在从企业自律走向半制度化接口。未来的争议点，很可能会落在“自愿”还能自愿多久。

AI锐评：监管最先盯上的不是聊天体验，而是模型会不会把网络攻防门槛继续拉低。

🔗 https://www.theverge.com/policy/941775/trump-ai-executive-order

💼 行业动态

Anthropic 扩大 Project Glasswing 安全计划

Anthropic 宣布扩大 Project Glasswing，把最初约 50 家合作伙伴扩展到约 150 家新组织，覆盖 15 个以上国家，并把电力、水务、医疗、通信、硬件等关键基础设施行业拉进来。官方披露，首批合作方使用 Claude Mythos Preview 扫描代码库后，已经找出超过 10,000 个高危或严重级别漏洞。新一轮扩张强调每个伙伴都必须先满足安全要求，且很多新增对象本身就是维护大量关键代码库的供应商。换句话说，Anthropic 正试图把“高级模型找漏洞”从展示能力，变成关键基础设施的常规安全流程。

AI锐评：如果这类项目继续有效，AI 在安全行业的第一波大单，可能不是防守聊天，而是漏洞清查。

🔗 https://www.anthropic.com/news/expanding-project-glasswing

🔓 开源热榜

Headroom 开源压缩大模型输入上下文

Headroom 的切口非常直接：不去改模型，而是压缩进入模型前的工具输出、日志、文件和 RAG 片段。GitHub 首页把价值写得很清楚——在保持答案质量接近不变的前提下，把 token 消耗压低 60% 到 95%，并同时提供 library、proxy 和 MCP server 三种落地方式。对今天大量依赖 agent 调工具链的团队来说，真正烧钱的往往不是主提示词，而是长日志、长检索结果和冗余上下文。谁先把这部分做薄，谁就先拿到更低的推理账单。

AI锐评：很多团队还在纠结换哪个模型，其实先把“喂进去的垃圾”压缩掉，省钱速度更快。

🔗 https://github.com/chopratejas/headroom

Impeccable 开源，主打修复 AI 前端审美同质化

Impeccable 不是传统组件库，而是一套专门喂给 AI harness 的 design language，目标是让生成式前端不再千篇一律。聚合页称它内置 23 个命令来快速优化网页视觉，而 GitHub 标题则把自己定义为“让 AI harness 更会做设计”的设计语言。也就是说，它试图把审美规则、排版习惯和视觉约束前置成可复用语言，而不是让模型每次临场发挥。对大量用 agent 先出前端草稿的团队来说，这比再换一个模型更直接，因为问题常常不是“不会写”，而是“写得都一个味”。

AI锐评：前端审美终于开始被当成基础设施，而不是 prompt 玄学。

🔗 https://github.com/pbakaus/impeccable

ECC 开源智能体优化系统冲上 GitHub 热榜

ECC 把自己定义为 agent harness performance optimization system，面向 Claude Code、Codex、Opencode、Cursor 等多类开发代理。GitHub 页面强调，它不是单点插件，而是把 skills、instincts、memory、安全和 research-first development 打包成一整套运行方法。换句话说，它瞄准的是“代理怎么长期稳定产出”这个工程问题，而不是单次 demo 漂不漂亮。随着 coding agent 从玩具进入日常生产，这类围绕记忆、权限和工作流约束的系统化工程，价值会越来越高。

AI锐评：下一阶段最稀缺的不是又一个聊天窗口，而是能把代理跑稳的工程底盘。

🔗 https://github.com/affaan-m/ECC

💼 行业动态

AI Alliance 推出主权模型项目 Tapestry

AI Alliance 发布 Project Tapestry 工作坊报告，明确把“主权 AI”从政治口号往工程路线图推进。报告显示，联盟在 5 月 7 日到 8 日于巴黎召集约 30 位研究者和机构代表，先产出四项早期成果：联盟式 frontier model 开发架构、主权数据/算力/下游适配共识、围绕文化对齐与分布式权重更新的工作流，以及依托非营利结构推进组织化协作的路径。它最值得注意的一点，是公开承认“没有 frontier performance，就没有真正可用的主权 AI”。这意味着开源阵营不再满足于讲价值观，而开始正面回答性能和协作怎么做。

AI锐评：主权 AI 如果只讲控制权、不讲能力上限，最后还是会被最强闭源模型吸走用户。

🔗 https://thealliance.ai/blog/project-tapestry-the-path-to-frontier-sovereign-ai
