TODAY'S FOCUS

Anthropic 携手 SpaceX 大幅上调 Claude 使用限额

Anthropic 与 SpaceX 宣布算力合作协议，Claude Pro 用户的使用限额随即大幅提升。SpaceX 旗下 Colossus1 数据中心将为 Anthropic 提供超过 22 万颗英伟达 GPU 的算力支持，这也是 SpaceX 合并 xAI 后首次对外提供 AI 算力服务。对重度使用 Claude 的用户而言，5 小时内的对话次数限制将显著放宽。此次合作标志着 AI 基础设施商业化进入新阶段——算力不再只是自用资源，而成为可以对外变现的核心资产，也预示着大模型公司与算力提供方的边界正在模糊。

算力合作把昨天的竞争关系变成今天的供应商关系，商业世界就是这么现实。

🔗 https://www.anthropic.com/news/higher-limits-spacex

🤖 Claude & Anthropic

Claude 推出智能体梦境功能，多 Agent 编排开放公测

Anthropic 为 Claude 发布「智能体梦境（Agent Dreams）」预览版功能，旨在提升智能体的多步骤逻辑推理能力。同步开放公测的还有多智能体编排框架和 Webhook 支持，开发者可通过 Outcomes 框架构建和交付自动化任务流。这批更新被视为 Anthropic 推进 Agent 战略的关键一步，使 Claude 从单轮对话工具向持续运行的自主代理演进。结合同期上线的托管代理功能，Claude 的 Agent 生态正在快速成形。

Agent 功能一次性上了好几个，Anthropic 这是在认真打 Agent 这张牌。

🔗 https://x.com/claudeai/status/2052067399088664981

Claude 托管代理功能上线，开发者无需自建服务器

Claude 官方平台正式推出托管代理（Managed Agents）功能，开发者可在 claude.com 控制台直接创建和管理自动化 AI 智能体，无需自建服务器和运行环境。托管代理支持调用外部 API、执行定时任务和跨系统协作，大幅降低了 Agent 部署门槛。此前 Claude API 用户需要自行搭建运行环境，新功能将基础设施运维交给 Anthropic 托管，开发者可以专注于业务逻辑。这与 OpenAI 的 Codex Agent 和 Google Project Mariner 形成直接竞争。

开发者不用自己搭服务器跑 Agent 了，门槛降低意味着用的人会更多。

🔗 http://claude.com/blog/new-in-claude-managed-agents

Anthropic 内部已部署数百 Claude Agent，实现全自动运营

Anthropic 内部已部署数百个 Claude Agent，在 Slack、GitHub 等工作协同工具中承担数据清洗、代码审核、跨组协作等日常运营任务，实现全天候自动化处理。这种「AI 运营公司」的模式与 Anthropic 此前提出的 Agent 战略高度吻合——不仅对外卖 Agent 产品，也在内部以 Agent 驱动运营效率。多位业内人士指出，Anthropic 此举相当于在为 Agent 产品做活体验证，运营数据可直接反哺模型和产品迭代。

自己吃自己的狗粮，而且吃到运营层面——这才是真正的 Agent First。

🔗 https://x.com/frxiaobei/status/2051824887971614950

⚡ 技术 & 产品

OpenAI 联合英伟达、微软发布 MRC 网络协议

OpenAI 携手英伟达与微软共同发布 MRC（Multi-Rail Communication）网络协议，专为超大规模 GPU 集群设计。该协议有效缓解万卡以上算力集群中的网络拥塞问题，减少因通信延迟造成的 GPU 空转浪费。微软和英特尔已在自有集群完成部署验证，实测证明对大模型训练效率有显著提升。随着大模型训练规模持续扩大，网络通信效率已成为算力利用率的关键瓶颈，MRC 协议被视为突破这一瓶颈的重要基础设施创新。

训练集群的网络瓶颈终于有人认真在解，万卡集群的效率提升空间很大。

🔗 https://openai.com/index/mrc-supercomputer-networking/

ChatGPT 进驻 Excel，GPT-5.5 直接内嵌办公套件

搭载 GPT-5.5 的 ChatGPT 办公助手正式登陆 Excel，用户可在表格内直接唤起 AI 完成公式编写、数据解读和自动化分析，无需切换应用。微软此前已在 Word、Outlook 等套件嵌入 Copilot，这次 ChatGPT 原生进驻 Excel 进一步模糊了两家产品的边界。对于日常重度使用 Excel 的企业用户而言，AI 辅助分析将从可选项变为默认工作流的一部分。此举也被视为 OpenAI 绕过微软渠道直接触达办公场景用户的战略举措。

Excel 里能直接问 AI，这对数据分析岗位的日常工作影响会很实际。

🔗 https://chatgpt.com/apps/spreadsheets/

🔬 前沿研究

OpenSeeker-v2：万条数据打破搜索垄断

学术团队发布 OpenSeeker-v2，仅使用万条数据通过 SFT（监督微调）训练，在多项搜索基准上超越谷歌、百度等头部产品。论文详细披露了训练方法和数据筛选策略，模型权重已完全开源，供社区复现和二次开发。这一成果再次印证了「数据质量 > 数据量」的训练范式，也表明搜索领域并非大厂专属——小团队在垂直任务上同样可以弯道超车。该研究预计将影响下一阶段信息检索类模型的训练方向。

万条数据超越大厂，数据质量再次证明比数据量更重要。

🔗 https://arxiv.org/pdf/2605.04036

ClawMark：主流 Agent 长流程成功率仅 20%

研究团队发布 ClawMark，专门针对「智能同事」场景设计的 Agent 评测框架，包含 100 项模拟真实办公任务的测试，通过脚本自动评分消除主观偏差。测试结果显示当前主流模型在长流程任务中的成功率仅约 20%，揭示了现有 Agent 产品与实际可用之间仍有显著差距。ClawMark 发布时间与 SWE-Bench 新基准 0% 完成率报告形成呼应，共同向行业传递信号：现有 Agent 评测体系已经不够用了，需要更贴近真实工作场景的测试方法。

20% 成功率说明当前 Agent 产品还处于早期，别被演示视频骗了。

🔗 https://arxiv.org/abs/2604.23781

⭐ 开源热榜

TabPFN：表格数据基础模型，挑战 XGBoost 的统治地位

PriorLabs 开源的 TabPFN 在 GitHub 收获 6500+ 星，专为表格数据分类任务设计，可秒级完成自动分类且无需手动调参。传统机器学习方法在表格数据上仍占主导地位，TabPFN 通过预训练基础模型的方式挑战这一格局。在多个公开数据集上，TabPFN 的准确率超越了 XGBoost、LightGBM 等经典方法。对于数据科学从业者而言，这类工具有望将模型选型和调优的时间从数小时压缩到几分钟，显著降低机器学习工作流的门槛。

表格数据终于也有基础模型了，XGBoost 的地位开始动摇。

🔗 https://github.com/PriorLabs/TabPFN

Agent-Skills 工程能力库，GitHub 30k 星爆火

前谷歌工程师 Addy Osmani 发布的 Agent-Skills 工具包在 GitHub 收获 30400+ 星，为 AI 智能体提供代码执行、文件读写、网络请求等标准化工程能力接口。这一项目的爆火反映了开发者社区对 Agent 工程化基础设施的强烈需求——当前各家 Agent 框架在基础能力封装上重复造轮子，标准化工具包有望成为行业公共基础设施。对于正在构建 Agent 产品的团队，引入成熟工具包可显著缩短开发周期。

30k 星说明开发者社区在认真搭 Agent，而且需要标准化的基础工具。

🔗 https://github.com/addyosmani/agent-skills

本地深度搜索工具爆火，SimpleQA 测试准确率 95%

LearningCircuit 开源的 local-deep-research 在 GitHub 收获 5600+ 星，支持本地部署（只需一张 3090 显卡），可接入 Ollama 本地模型或主流云端 API，在 SimpleQA 测试中达到 95% 准确率。与在线搜索工具相比，本地版本的核心优势是数据不离本地，适合企业内部知识库检索和隐私敏感场景。随着本地大模型能力持续提升，这类工具的实用性正在快速提高，有望成为企业私有化部署 AI 搜索的首选方案。

本地跑搜索 + 95% 准确率，隐私场景的刚需终于有了好用的工具。

🔗 https://github.com/LearningCircuit/local-deep-research
