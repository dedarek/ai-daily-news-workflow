今天的主线很清楚：Anthropic 一边更新 Claude Opus 4.8，一边把 Claude Code 推向多智能体工程系统，模型公司继续朝平台公司演化。另一边，Waymo、东京机器人峰会、Gemma 3 边缘开发板和 NVIDIA 视觉定位模型说明 AI 正在从“云端会话”继续外溢到汽车、机器人、终端设备和界面操作。资本市场也没有降温，Anthropic 逼近万亿美元估值、AI token futures 讨论升温，说明算力和调用成本已经开始被当成真正的生产资料对待。如果把这些信号连起来看，AI 竞争正在同时卷模型、卷工作流、卷硬件和卷金融基础设施。

🔥 今日焦点

焦点

Claude Code 上线 Dynamic Workflows 动态多智能体工作流

Claude Code 这次放出的不是一个小功能，而是一套把大型工程任务拆成多代理并行执行的工作流系统。官方博客把重点放在“自主脚本调度数百个智能体”上，适用场景包括大规模代码迁移、发布前对抗性测试和复杂工程编排。它意味着 Claude 的产品方向正在从“给你一个会写代码的模型”，转向“给你一套能组织工程生产的 agent runtime”。对企业用户来说，这比单次生成代码更关键，因为真正贵的是迁移、验证、回归和协作。

锐评：Anthropic 这步不是卷模型分数，而是抢“团队级工程自动化”的入口。谁先把多代理 workflow 做成默认心智，谁就更像下一代开发平台。

🔗 https://claude.com/blog/introducing-dynamic-workflows-in-claude-code

🚀 产品发布

Claude 发布 Opus 4.8 与快速模式降价

Anthropic 同一天还放出了 Claude Opus 4.8，并强调新版在判断力、交互诚实度和响应效率上的改进。更值得注意的是快速模式降价，这说明它不只是想秀旗舰能力，而是想把高性能模型推到更高频的真实使用场景里。模型层和 workflow 层同时更新，等于把“更强的大脑”和“更大的执行系统”一起打包。对开发者来说，这通常意味着后面会有一轮新的工具链适配和成本重算。

锐评：只发最强模型已经不够了，头部厂商现在都得同时回答两个问题：够不够强，和用起来贵不贵。Anthropic 这次明显是两边都想守住。

🔗 https://x.com/claudeai/status/2060042702150930686?s=20

Waymo 新一代极氪定制 Robotaxi 开始接客

Waymo 开始让为运营场景定制的 Zeekr RT 无人车在美国城市里接客，这件事比“又一辆无人车上路”更重要。TechCrunch 把重点放在“为赚钱而设计”——也就是围绕车队运营、成本控制、乘坐空间和维护效率重新做车型，而不是把量产私家车强行改成 Robotaxi。自动驾驶商业化过去卡在技术、法规和单车 economics 三个环节，这类定制车型就是在直接啃第三块硬骨头。对整个 physical AI 赛道来说，能不能把单位运营成本打下来，比演示视频更有说服力。

锐评：自动驾驶真要起量，拼的不是 demo 漂不漂亮，而是每一单能不能赚钱。Waymo 终于开始像运营商，不只是实验室。

🔗 https://techcrunch.com/2026/05/28/waymos-newest-robotaxi-is-chinese-made-built-to-make-money-and-now-accepting-riders/

NVIDIA 发布 Locate Anything 视觉定位模型

NVIDIA 研究团队公开的 LocateAnything，核心卖点是把视觉语言定位做得更快也更准。公开页面明确提到它支持文档理解、GUI grounding、密集目标检测和 OCR 定位，并用并行框解码来提升吞吐。这个方向的价值在于，它不是单纯给机器人或摄像头用，也可以直接服务于桌面自动化、智能体操作界面和企业文档理解。换句话说，视觉 grounding 正在从“科研酷炫 demo”进入 agent 基础能力层。

锐评：很多人盯着大模型会不会思考，NVIDIA 盯的是模型能不能准确点到屏幕上的那个按钮。后者更接近赚钱。

🔗 https://research.nvidia.com/labs/lpr/locate-anything/?linkId=100000424057485

Google 推出可本地运行 Gemma 3 的微型开发板

Google 展示这块可本地运行 Gemma 3 的微型开发板，释放的是一个很清楚的信号：边缘端模型部署不会只停留在手机和 PC。官方强调 1 TOPS 算力、低功耗和嵌入式开发友好，意味着它瞄准的是机器人、传感器、工业设备和各种 always-on 终端。过去大家讨论边缘 AI 往往只看模型能不能塞进去，现在更现实的问题是：板卡、SDK、功耗和维护链路能不能一起打通。Google 这次是在把 Gemma 往“开发平台”而不是“下载权重”推进。

锐评：云端模型卷到今天，下一轮差异化一定发生在“谁能把模型真正塞进设备并稳定跑起来”。板卡比发布会口号更能说明问题。

🔗 https://the-decoder.com/google-launches-a-tiny-board-that-runs-gemma-3-locally/

💼 行业动态

Anthropic 融资 65 亿美元后估值逼近万亿美元

The Decoder 援引的融资信息显示，Anthropic 在新一轮 65 亿美元融资后，估值继续往万亿美元级别靠近，年化营收也被推到 40 亿美元以上。这个数字本身固然夸张，但更值得看的是资本市场给出的判断：头部模型公司的故事，已经不只是“未来可能很大”，而是“现在就能开始吃到现金流”。今天 Anthropic 同时发模型、发工作流、讲平台化，也恰好解释了为什么资本愿意继续用更高估值买单。模型厂商之间的竞争，正在越来越像云厂商和操作系统公司的混合体。

锐评：估值膨胀当然有泡沫成分，但只要企业真在把预算从人力和 SaaS 挪到 AI，这种泡沫就不会轻易自己破。

🔗 https://the-decoder.com/claude-company-anthropic-nears-a-trillion-dollar-valuation-after-raising-65-billion-in-series-h/

AI Token Futures 概念升温，算力与 Token 被做成可交易标的

TechCrunch 讨论 AI token futures 的文章很值得细看，因为它抓住了一个很多人忽略的变化：Token 正在从抽象的 API 计费单位，变成可以被金融化的生产要素。只要企业把模型调用成本当成核心经营变量，就会自然出现锁价、对冲、远期合约这些传统大宗商品世界的工具。它背后的逻辑是，AI 推理已经越来越像电力、带宽和云资源，而不是一项“实验性功能”。一旦这个市场真的成形，模型公司、云平台和交易基础设施之间的边界会被重新改写。

锐评：当行业开始讨论 token 期货，说明 AI 已经不只是技术竞赛，而是在往真正的大宗生产体系里钻。听起来荒诞，但很可能是真的。

🔗 https://techcrunch.com/2026/05/28/just-like-gold-and-oil-well-soon-be-able-to-trade-ai-token-futures/

德州自动驾驶登记显示 Waymo 领先 Tesla

另一篇 TechCrunch 报道补上了 Robotaxi 商业化的另一面：在德州自动驾驶车辆注册数据里，Waymo 的登记规模明显领先 Tesla。这个差距说明，哪怕 Tesla 在公众注意力上始终占优，真正进入监管、落地和运营体系时，节奏并不一定更快。自动驾驶的竞争已经越来越像一个长跑项目，拼的是合规推进、车队运营、地理扩张和持续稳定性。对资本市场来说，这种“谁先真正跑起来”比创始人的叙事更重要。

锐评：自动驾驶行业最残酷的一点是，流量不会自动变成运营能力。Tesla 在叙事上很强，但 Waymo 在表格里更强。

🔗 https://techcrunch.com/2026/05/28/waymo-dominates-texas-autonomous-vehicle-registrations-as-tesla-trails-behind/

🇨🇳 国内 AI

Huawei 表态探索超越摩尔定律的 AI 芯片路线

Reuters 报道里最关键的信息，不是“华为又说了一句狠话”，而是它把芯片路线从追赶先进制程，进一步转向系统级架构和超越摩尔定律的叙事。这个表态说明，在外部限制短期难松动的情况下，国内厂商已经越来越明确地接受一个现实：AI 算力竞赛未必只能靠最先进制程硬拼，还可以靠互连、封装、体系结构和软硬协同找替代路径。这个方向不会一夜见效，但它决定了未来几年国产 AI 基础设施到底是继续被动补位，还是开始形成自己的技术语法。

锐评：先进制程当然重要，但把全部希望押在“等别人放开”上没有意义。路线切换本身，就是产业成熟的开始。

🔗 https://www.reuters.com/technology/artificial-intelligence/huawei-looks-beyond-moores-law-2026-05-27/

🤖 具身智能

东京机器人峰会展示具身智能最新进展

东京举行的人形机器人峰会把很多“physical AI”概念拉回了实物层面。现场报道里最抓人的细节，是机器人已经能做到接近穿针引线级别的精细操作，而不只是搬箱子、走路和站立。这说明行业正在同时攻克力量控制、末端执行器设计、传感反馈和视觉理解，而不是只卷大模型。对于具身智能创业公司和工业自动化玩家来说，真正的分水岭不是会不会说话，而是能不能稳定、重复、低故障地完成高精度动作。

锐评：能把针穿进去的机器人，比会聊天的机器人更接近现实世界的 ROI。physical AI 终于开始脱离 PPT。

🔓 开源热榜

ECC 开源：面向智能体性能与安全强化的框架

GitHub 上爆红的 ECC 项目，把“agent harness performance optimization system”讲得很直接：它想同时解决技能复用、记忆、安全、研究优先开发和执行效率问题。今天的 coding agent 热度很高，但不少团队已经意识到，真正难复用的不是模型本身，而是围绕模型搭起来的脚手架系统。ECC 之所以能吸引关注，是因为它踩中的不是某一个模型的能力短板，而是整个 agent 工程化的系统缺口。开源社区现在最缺的，正是这种能把零散 best practices 重新打包成方法论的项目。

锐评：大家都在追新模型，聪明人已经开始补“模型外面那层真正决定交付质量的壳”。ECC 走红不偶然。

🔗 https://github.com/affaan-m/ECC

Understand Anything：面向大代码库的结构化理解工具走红

Understand Anything 的卖点非常朴素：把复杂代码库变成一个可探索、可搜索、可提问的知识图谱。它之所以火，不是因为做了什么特别玄的 AI 魔法，而是因为所有 coding agent 都在被同一个问题折磨——上下文太大，结构太散，模型看不懂仓库全貌。这个项目本质上是在给人类开发者和智能体同时补一层“架构导航系统”，特别适合大型仓库的依赖梳理、模块理解和任务切分。模型越来越强之后，代码理解工具反而变得更值钱，因为高质量上下文决定了高质量输出。

锐评：如果说大模型是发动机，那代码图谱就是导航。没有导航，再强的发动机也可能把项目开进沟里。

🔗 https://github.com/Lum1104/Understand-Anything

锐评：AI 电影真正威胁的不是大片，而是中低成本内容生产的旧秩序。门槛一掉，游戏规则就会一起掉。
