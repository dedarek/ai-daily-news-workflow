阿里Qoder推出Cloud Agents，Agent上线仅需1天

今天，阿里Qoder上线Cloud Agents，这是全托管的AI Agent运行平台，可提供Agent底座、模型服务及运行环境等全栈Agent能力，企业可通过API的方式直接调用，让应用和业务系统快速长出“大脑”和“双手”，Agent 上线时间从1个月缩短至1天。 国内外主流通用Agent工具正在快速提升个人的工作效率，但此类工具无法深度集成至千行百业的应用场景，企业要开发一个能长期运行并适配业务场景的Agent，需要手动搭建和管理推理执行引擎、运行沙箱、长程会话等，开发到上线一个Agent耗时长达一个月。 Cloud Agents将Agent开发和运行的全套流程封装成统一的托管服务，企业可以像使用云产品一样调用完整的Agent能力。 它由Qoder底层Coding Agent 引擎驱动，具备理解复杂需求、调用工具、执行长程任务与容错恢复等通用能力，无需改动一行代码，无论是客服、运营、风控还是运维都可直接接入。 在运行环境方面，Cloud Agents可为每个Agent提供独立的沙箱，每一次工具调用、每一步推理均可通过SSE事件流实时推送，全程可追踪、可回放、可审计，不仅可以保障业务的数据安全，还能根据业务并发情况自动扩缩容。

AI锐评：企业级 Agent 真正的门槛从来不是“能不能跑 Demo”，而是能不能把运行、审计、扩缩容和沙箱一起交付。Qoder 这次把“上线时间”从月级压到天级，打的是平台层的硬仗。

🔗 https://qoder.com/cloud-agents

阿里云百炼CLI开源！一行命令，AI Agent 即刻接入

今天，阿里云百炼核心能力已CLI化 ，仅需一行命令，即可让Agent自动接入阿里云百炼的150多款模型、十多款应用，以及知识库、记忆、联网搜索等全套能力。 百炼CLI专为Agent设计，原生支持Claude Code、Qoder、OpenClaw、Hermes Agent等主流 AI Agent 框架，目前已在Github开源（modelstudioai/cli）。 一行命令，把阿里云百炼能力接入 AI Agent 过去，百炼平台的交互逻辑为人而设计，开发者需要分别理解不同模型API、鉴权方式、参数结构和工具封装方式。 阿里云百炼 CLI 将这些能力封装为统一、轻量、可脚本化的命令行入口，让 Agent 可以用更自然的方式调用阿里云百炼平台能力。 开发者只需把安装、鉴权和任务描述交给Agent，即可在自己的 Agent 工作流中完成调用。

AI锐评：CLI 化不是简单换个壳，而是把“人用平台”改造成“Agent 可调用的能力层”。谁先把模型、知识库、搜索、文件处理这些能力标准化，谁就更可能吃到 Agent 编排红利。

英伟达清华团队提出Gamma-World：世界模型从「一个人玩」到「多人共处」

当前视频世界模型在单智能体设定下已经走得相对成熟。 但多智能体场景—— 多个玩家共享同一个演化世界 ，在架构层面一直缺乏系统性的解决方案。 问题不在于算力不够，而在于现有的位置编码和注意力机制，从设计上就没有为多个主体预留接口。 近日， NVIDIA联合清华大学、多伦多大学和Vector Institute发布Gamma-World（γ-World） ，从RoPE扩展和注意力拓扑两个底层组件入手，给出了一套系统性的答案。 论文标题： Gamma-World: Generative Multi-Agent World Modeling Beyond Two Players 为什么多智能体世界建模是一个困难问题 现有视频世界模型几乎都建立在单智能体假设之上： 给定一个玩家的动作序列，预测该视角下的未来观测。

AI锐评：单智能体视频预测已经开始卷成熟，多智能体共享世界才是下一段硬仗。Gamma-World 把“多人共处”的接口问题拆到位置编码和注意力拓扑层，方向很对。
