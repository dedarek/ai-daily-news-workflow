🔥 今日焦点

焦点

OpenAI 继续推进“超级应用”计划

TechCrunch 披露 OpenAI 仍在开发一个更完整的超级应用形态，试图把聊天、记忆、工具调用和更多原生能力整合到单一体验里。报道指向的重点不是单一新功能，而是 OpenAI 试图把 ChatGPT 从产品升级为平台。结合外部报道，这意味着 OpenAI 正在把多种能力封装成统一入口，既包括对话与记忆，也可能包括 agent 执行、内容生成和服务分发，背后是对用户时长、工作流入口和生态控制权的争夺。

AI锐评：OpenAI 想要的不是再加一个功能，而是把用户的入口、记忆和工作流都锁进自己的壳里。谁先把“聊天工具”做成“默认操作层”，谁就可能吃下下一轮平台红利。

🔗 https://techcrunch.com/2026/06/07/openai-is-still-working-on-that-super-app/

🤖 Agent & 工具

Perplexity 发布 Search as Code 搜索架构

Perplexity 把搜索能力改造成可编程的 code generation 流程，让模型在沙箱里动态编写和执行搜索脚本，而不是只调用固定 API。官方称这一参考架构面向 Agent 检索与推理场景，目标是在准确率、成本和灵活性之间取得更好的平衡。结合官方研究页可知，这套 Search as Code（SaC）架构把搜索流程拆成更细粒度的可编程原语，核心卖点是让检索过程可被模型主动重写与组合，适配更复杂的 agent workflow。

AI锐评：把搜索从“接口调用”变成“代码生成”之后，Agent 的上限会被明显抬高。真正危险的不是 Perplexity 做了个新架构，而是它证明搜索本身也可以被模型重写。

🔗 https://research.perplexity.ai/articles/rethinking-search-as-code-generation

Goose 开源代理重构软件工程工作流

开源项目 goose 继续受到关注，定位是适配多模型的全能代理系统，可自主运行自动化测试并衔接开发流程。它的意义不只是再造一个聊天壳，而是试图把 agent 真正塞进工程流水线。若此类项目继续成熟，开发团队会越来越少讨论“选哪个模型”，转而讨论“如何定义代理的权限、记忆、验证和回滚机制”，这会让软件工程工具链进一步 agent 化。

AI锐评：工程团队下一步拼的不是谁先接上模型，而是谁先把验证、权限和回滚机制嵌进代理工作流。没有这些护栏，所谓全能代理大多只是高配版脚本。

🔗 https://github.com/aaif-goose/goose

论文质疑 AGENTS.md 对 Coding Agent 的净收益

arXiv 论文讨论仓库级上下文文件对 coding agent 的真实帮助，结论并不简单：自动生成的大而全上下文文件可能拉高 token 成本，甚至拖累任务成功率。上下文不是越多越好，而是越贴任务越好。这个结论对 AI 编程工作流很关键，因为它挑战了一个流行假设——给代理塞更多背景，并不一定会得到更好的执行结果。

AI锐评：这篇论文最值钱的地方，是把一个流行错觉捅破了——上下文不是越多越好。给代理喂一大堆背景，很可能只是把噪音包装成“认真做事”。

🔗 https://arxiv.org/abs/2602.11988

🔐 安全 & 风险

SafeBreach 披露 Gemini 语音助手可被通知注入操纵

SafeBreach 发布研究称，攻击者可以借由消息通知里的恶意内容，对 Android 上的 Gemini Voice Assistant 发起 indirect prompt injection，从而诱导助手执行未经授权的动作。问题不在单一 prompt，而在通知、语音助手和系统权限链路的联动。SafeBreach 原始研究进一步指出，攻击载体可以来自 WhatsApp、Slack、SMS、Signal 等通知内容，看似普通的消息实际可能成为操纵语音助手的提示词通道，这对系统级 AI 助手的信任边界是一次直接冲击。

AI锐评：系统级 AI 助手最怕的不是答错题，而是被外部输入悄悄借壳。提示词注入一旦进入通知、语音和系统权限链路，安全后果会比网页聊天高一个量级。

🔗 https://www.safebreach.com/blog/gemini-voice-assistant-prompt-injection-exploit

💡 前沿研究

Google Research 发布 TurboQuant 压缩方案

Google Research 介绍 TurboQuant 极限压缩方法，声称可在零精度损失前提下显著压缩模型与 KV cache 占用，用于提升推理阶段的显存效率和向量检索效率。对长上下文推理来说，这类方法直接对应部署成本。它的现实意义不是单点提速，而是让更长上下文、更低成本、更高吞吐可以同时成立。

AI锐评：很多公司嘴上卷模型，账本上卷显存。谁能把长上下文成本压下去，谁就更可能在企业部署里赢得真实订单。

🔗 https://research.google/blog/turboquant-redefining-ai-efficiency-with-extreme-compression/

Biohub 开源蛋白生物学世界模型

Biohub 宣布发布 world model of protein biology，试图把蛋白结构预测、跨物种映射和 binder 设计统一到一个科学发现引擎里。与此前单点预测工具相比，这更像是朝“生物学基础模型平台”迈进一步。Biohub 官方说明则补充了更关键的落点：该模型不仅面向结构预测，还服务于设计与实验验证，目标是把蛋白生物学中的表示、推理和生成统一到同一套 AI 系统中。

AI锐评：如果说通用 LLM 在重写知识工作流，蛋白世界模型就是在重写实验室工作流。科研 AI 真正的含金量，不在 demo，而在能不能把实验成功率和设计效率一起拉起来。

🔗 https://biohub.org/news/world-model-of-protein-biology/

💼 行业动态

英伟达在开源模型热榜持续霸榜

英伟达近期密集发布模型并在多个开源热榜占据高位，显示其正在从硬件公司继续向模型与生态层延伸。重点不只是发新模型，而是以完整基础设施优势绑定开发者。这条动态反映的是英伟达近两个月在开源侧的持续推进：一边通过 CUDA、TensorRT、NIM 与推理堆栈固化开发路径，一边用开源模型、基准展示和生态合作占住开发者注意力。若其在热门榜单上的存在持续增强，GPU 之外的话语权也会随之上移。

AI锐评：英伟达现在最可怕的地方，不是卡卖得多，而是开始同时占硬件、框架、模型和榜单。它正在把“AI 基础设施公司”四个字越写越满。

AI锐评：十万卡不只是炫富，这是把模型竞争推成重工业。今后的头部模型发布会，越来越像电厂、园区和供应链的联合路演。

Newspim 报道韩国总统提名科技精英为国务总理，强调以 AI 转型和产业升级为核心方向。政治层面的含义是，AI 已经不再只是产业政策议题，而被提升到国家级治理与增长战略。若韩国高层人事安排确实与 AI 产业升级强绑定，后续可能带动算力、数据、机器人、半导体和数字政务等多个板块的统筹推进，也意味着东亚国家对 AI 竞争进入更强的政府主导阶段。

AI锐评：AI 正在从产业政策升级成国家治理议题。谁把 AI 放进总理级别的人事和预算框架，谁就说明这件事已经不再是科技圈自嗨。

C3 AI 为壳牌上线预测性维护智能代理

🔓 开源热榜

OpenCV 持续更新实时视觉处理核心库

OpenCV 仍然保持高热度，说明 AI 时代的视觉底座并没有被端到端大模型完全替代。很多实时处理、边缘部署和工业视觉环节，仍然依赖稳定的经典计算机视觉库和工程接口。这个信号很重要：无论大模型多火，真正进入设备、相机和机器人系统时，开发者最终还是要面对性能、延迟、兼容性和部署成本，而 OpenCV 仍然是这些问题的通用入口。

AI锐评：AI 再火，到了设备侧还是得回到工程现实。OpenCV 这种老牌基础库还在涨热度，说明经典 CV 远没有被大模型淘汰。

🔗 https://github.com/opencv/opencv

Taste Skill“去 AI 油腻感”工具爆火

Taste Skill 是一个主打改善审美与表达风格的开源工具，核心诉求不是提升模型能力上限，而是减少 AI 输出中的模板感、塑料感和“工业废话”。这类项目热起来，说明用户开始从“能用 AI”转向“受不了 AI 味”。这个趋势值得注意：当基础生成能力越来越普及，真正拉开差距的会从模型本身转向 taste、editing 和 human-in-the-loop 的后处理环节，工具层也会随之出现更多“反 AI 味”的精细化产品。

AI锐评：用户已经从“我想要 AI 帮我生成”进化成“求你别再给我 AI 味了”。审美修正层会是下一波内容工具的重要战场。

🔗 https://github.com/Leonxlnx/taste-skill

Open Design 发布 anti-AI-slop 设计指南

Open Design 项目公开 anti-ai-slop 设计指南，试图帮助团队摆脱“模板味”“渐变堆料”和 emoji 滥用等常见 AI 生成设计问题。它反映出一个更成熟的市场阶段：用户已经不满足于自动生成，而开始系统性修正生成审美。对设计团队来说，这类指南的价值不是提供单个视觉模板，而是建立一套识别低质 AI 输出的审稿标准，让 AI 参与设计时不至于越做越“油”。

AI锐评：当大家都能一键出图和出页面，真正稀缺的是“知道什么该删”。反 AI slop 不只是审美洁癖，而是品牌和产品感的保命线。

🔗 https://github.com/nexu-io/open-design/blob/main/craft/anti-ai-slop.md
