今天最值得关注的不是单点新品，而是 AI 正在同时向三个更硬的方向推进：一是从写代码走到操控实体设备，二是从聊天能力转向金融、医疗等高责任场景的流程重构，三是从单一模型竞争升级为数据、电力和工作流体系的全面比拼。Anthropic 用机器狗实验把“物理世界里的智能体”拉近了一大步；微软、汇丰和美国电网监管的动向，则说明大公司已经把模型与基础设施当成现实生意而不是未来概念。研究侧则继续猛攻世界模型、运动预测和长视频理解，这些能力会直接决定下一代机器人、互动内容和多模态代理的上限。如果说去年大家还在比谁更会说，今年已经明显变成谁更会做、谁能接入真实系统、谁能扛住成本与治理。

🔥 今日焦点

焦点

Anthropic 再测 Project Fetch：Claude 控制机器狗的任务速度最高快过人类团队 20 倍

Anthropic 公布了 Project Fetch 第二阶段结果，让 Claude Opus 4.7 在 Claude Code 里直接接管一只现成四足机器人。研究团队把任务拆成接入控制器、连接视频与激光雷达、编写控制程序、监控路径、识别沙滩球等多个环节，模型在有人审批命令但几乎不提供人工思路的条件下连续完成。按官方对比，在去年至少有一支人类队伍能做完的任务上，Opus 4.7 的速度至少快 10 倍；如果只看两支人类队伍都完成的四项任务，模型平均比“纯人工队”快 37 倍、比“人+Claude”队快 18 倍。更重要的是，模型写出的代码量比有人协作队少近十倍，说明能力提升不只是堆更多步骤，而是能更快锁定正确接口和控制路径。Anthropic 也承认它还没真正攻克精细抓取，尤其在闭环控制沙滩球回到起点时仍不稳定，但“先辅助人、再被人辅助、最后独立完成”的能力曲线已经从网络安全延伸到了实体世界。

AI锐评：这条最值得警惕的不是“机器狗会跑”，而是通用模型没有专门为机器人训练，却已经能把接线、调 API、写控制脚本这些脏活串成闭环。具身智能真正危险的时刻，往往不是机械臂更稳了，而是大模型学会自己把工具链接起来。

🔗 https://www.anthropic.com/research/project-fetch-phase-two

🚀 产品发布

越办推出可自主避障的老年助行马桶，把激光雷达卷进了养老硬件

上海公司越办展示了一款面向行动不便老人的自驱动马桶产品，核心卖点不是“智能联网”，而是它真的会自己移动。公开信息显示，这台设备配了激光雷达和自主避障能力，可以在室内环境里主动规划路径、绕开障碍物，再移动到使用者身边。对养老场景来说，这比传统“扶手+呼叫铃”更进一步，因为它试图解决的不是单点辅助，而是老人从床边、沙发到卫生间这一整段最容易跌倒的移动链路。类似产品过去更多停留在展会概念阶段，而这次的信号是，具身智能正在从机器人本体外溢到更细分、更高频的家庭器具。硬件难点也很直接：可靠性、清洁维护、室内导航鲁棒性和成本控制，任何一项没打磨好，都很难真正进家庭。

AI锐评：把机器人能力塞进马桶，听起来离谱，商业上却可能比“家用通用机器人”更先落地。越具体的需求，越容易先赚到钱。

🔗 https://www.theverge.com/tech/952441/yueban-xiaoban-self-driving-autonomous-toilet

百川智能继续押医疗：M4 模型把多轮问诊、病程记忆和推理路径打包升级

百川智能最新医疗模型 M4 的升级重点，不只是回答更像医生，而是把门诊里最麻烦的“连续追问”补进了产品形态。公开报道提到，这套系统强化了多轮临床问诊，能围绕症状、既往史、检查结果和病程变化持续追问，而不是单轮给一个泛泛建议就结束。它同时加入原子化推理路径和全病程记忆，意味着系统不是只做语言润色，而是尝试把问诊流程拆成更像临床决策树的结构化步骤。这个方向很现实，因为现在最常见的问题不是 AI 一句答错，而是患者拿着 AI 结论去医院“对答案”，反而把医患沟通成本抬高。谁能把追问质量、风险提示和信息留存做扎实，谁才有资格说自己真的在碰医疗场景，而不是只在做健康版聊天机器人。

AI锐评：医疗大模型的胜负手从来不是“会不会背医学知识”，而是敢不敢把追问做深、把不确定性说清。光会一本正经地下结论，临床上只会更危险。

GPT-5.6 与 GPT-5.6 Pro 进入测试视野，下一轮旗舰升级先卷多模态智能体

多方测试账号本周披露，GPT-5.6 与 GPT-5.6 Pro 已经出现在内部测试环境里，版本命名延续了当前旗舰和专业版的双轨结构。现有流出的关键信号不是“更大参数”这类空话，而是新版本可能继续强化多模态和智能体场景，把文本、图像、工具调用和执行链路捏得更紧。过去一年的主线已经很清楚：顶级模型竞争不再只是 benchmark 分数，而是谁能把推理、调用外部工具、长链任务执行和多模态输入一起稳定下来。若 5.6 系列真的落地，很可能意味着 OpenAI 会继续把高端能力切分成更适合企业工作流的层级版本。市场真正关心的不是编号升了多少，而是延迟、成本、工具可靠性和代码任务的收益能不能同步兑现。

AI锐评：旗舰模型现在最怕的不是“分数不够高”，而是升级完之后贵得离谱、慢得要命。版本号好看没用，执行链路才是生死线。

💼 行业动态

美国 FERC 给 AI 数据中心开并网快车道，但真正稀缺的发电能力还没补上

美国联邦能源监管委员会 FERC 已要求六大电网运营方加快处理数据中心等大负荷用户的并网申请，并在 30 天内上报可用发电余量、60 天内解释或修订区域电价机制。政策层面的信号非常明确：AI 数据中心不能再像普通工业负荷那样慢慢排队，因为算力扩张已经被视作国家竞争力问题。麻烦在于，快车道解决的是排队顺序，不是电从哪里来。报道提到，到 2023 年底，美国待并网的新电站申请量已经超过现有电站总装机容量，而数据中心用电需求到 2035 年预计还要接近翻三倍。在这种背景下，很多项目被迫转向更贵、更复杂的表后电源，自建燃气、地热甚至核能都重新成为热门选项。也就是说，AI 基建的瓶颈正在从 GPU 采购，进一步转向“有没有电、能不能尽快接上电”。

AI锐评：现在限制大模型扩张的，不一定是芯片，也可能是变电站。算力军备竞赛打到最后，拼的往往是电网和施工队。

🔗 https://techcrunch.com/2026/06/18/ai-data-centers-just-got-a-government-mandated-fast-lane-to-the-grid/

General Intuition 洽谈新一轮 3 亿美元融资，世界模型公司开始用游戏视频训练智能体

纽约创业公司 General Intuition 正在洽谈约 3 亿美元融资，估值约 20 亿美元。它的特别之处不在于又一家“世界模型”公司出现，而在于训练数据路线很不一样：团队源自游戏视频平台 Medal，手里握着每年约 20 亿段视频、1000 万月活用户产生的第一人称互动素材。公司要做的不是单纯卖世界模型，而是用这种高度交互、带空间和时间连续性的游戏数据去训练能够行动的智能体。TechCrunch 提到，这批数据曾吸引 OpenAI 关注，Jeff Bezos、Eric Schmidt 以及 Khosla Ventures、General Catalyst 等也已经入局。整个赛道的商业逻辑正在发生变化：过去世界模型更像酷炫 demo，现在越来越多公司开始把它视为机器人训练、仿真推演和行动智能体的底层数据引擎。

AI锐评：真正值钱的可能不是模型名字，而是别人复制不了的数据河道。谁掌握长时间、高交互、第一视角的视频资产，谁就更像在卖未来智能体的燃料。

🔗 https://techcrunch.com/2026/06/18/general-intuition-in-talks-to-raise-300m-at-around-2b-valuation/

微软成了 OpenAI 模型在中国的实际代理商，这门生意一年能跑出十亿美元级别

据外媒梳理，微软已经悄悄成为 OpenAI 模型在中国市场最核心的销售通道。OpenAI 和 Anthropic 基于知识产权与滥用风险考虑，并不直接向中国市场提供模型服务，但微软凭借与 OpenAI 的独家合同安排，可以通过 Azure 向字节跳动、蚂蚁集团、美团、腾讯等大型客户销售 GPT 系列模型。报道里最扎眼的数字是：字节跳动作为微软近年最大的 AI 客户之一，相关 AI 与云服务年支出正逼近 10 亿美元；微软中国区 Azure AI 收入也曾在一个财年里接近三倍增长。微软的做法很微妙：一边向中国企业卖美国模型，一边又把中国的 DeepSeek 引进 Azure，并测试微调版 DeepSeek-V4 给 Copilot Cowork 这类企业代理用。它赚的不是单边技术优势，而是站在跨境模型流通的中间层，把监管、分发和利润都握在自己手里。

AI锐评：别人还在吵“该不该卖”，微软已经开始赚“转手费”了。真正老辣的玩家，从来不站阵营里，他站在收费口。

HSBC 把 Gemini 和智能体平台推向全球业务，计划两年内落地 200 多个 AI 用例

汇丰与 Google Cloud 签下多年合作，将在财富管理、金融犯罪风险管理和内部决策支持三大方向推进 AI。根据公开信息，汇丰预计未来两年会落地 200 多个 AI 用例，其中部分项目单项就有望带来超过 1 亿美元的收入提升或效率收益。它本身已经不是 AI 新手：集团层面有超过 600 个 AI 用例，600 多个应用运行在 Google Cloud 上，2 万多名开发者已经在使用编码助手，平均编码效率提升约 15%。在金融犯罪场景里，汇丰和 Google 之前联合开发的 Dynamic Risk Assessment 系统据称能把检出量提升到旧方法的 2 到 4 倍，并且银行每月监控的交易量超过 12 亿笔。相比空泛的“银行拥抱 AI”，这次更像是大型金融机构正式把生成式 AI 和 agentic AI 写进核心运营指标。

AI锐评：金融业一旦开始给 AI 项目写明确 ROI，行业就进入真刀真枪阶段了。PPT 时代结束，接下来拼的是谁敢把风控、交易和客服真正交给模型提速。

💡 前沿研究

MaineCoon 发布 22B 音视频世界模型，号称实时生成可跑到 47 帧

MaineCoon 论文把目标直接瞄准“实时音视频社交世界模型”。公开页面显示，这是一套约 220 亿参数的自回归框架，强调在同时处理语音、视频和社交互动线索时仍能维持高吞吐，生成速度最高可到 47 FPS。这个数字为什么关键？因为过去很多世界模型 demo 看起来很惊艳，但一旦要进入实时交互场景——例如角色对话、虚拟陪伴、游戏 NPC 或直播数字人——延迟就会立刻暴露。MaineCoon 的价值不只是更会生成，而是试图把“可互动”“有时间连续性”“音视频同步”这三件事压进同一条技术栈里。如果后续开源细节和复现数据也站得住，它会给社交陪伴、互动娱乐和虚拟世界类产品一个非常直接的参考模板。

AI锐评：世界模型以前像会画画的电影海报，现在开始学会“实时演戏”了。帧率一旦起来，商业化想象空间会比 benchmark 漂亮得多。

🔗 https://huggingface.co/papers/2606.17800

MolmoMotion 用语言指令预测 3D 点轨迹，想把机器人抓取和视频运动理解接上

Allen Institute for AI 推出的 MolmoMotion 把问题设定得很明确：给定语言指令，模型要预测空间中物体点位接下来怎么运动。公开摘要显示，这项工作覆盖了大规模运动数据，希望让系统既能理解“往哪动”，也能理解“为什么这样动”。这种能力对机器人抓取、机械臂路径规划和视频生成都很关键，因为很多现有模型会看图、会分割，但对连续运动轨迹的建模仍然很弱。真正困难的地方在于，语言描述往往是抽象的，而 3D 轨迹需要极具体的时空推断，所以它本质上是在测试模型把语言约束翻译成物理运动的能力。如果后续评测表现稳定，这类框架会是具身智能和可控视频生成之间的一座桥。

AI锐评：让模型“看见”一只手不难，让模型提前猜到它下一秒怎么动，才是真本事。空间预测一旦做稳，机器人和视频都会一起升级。

🔗 https://huggingface.co/papers/2606.18558

主动感知进入多模态推理主线，小模型也开始靠“先找再想”抬高长视频理解上限

论文 Native Active Perception as Reasoning for Omni-Modal Understanding 把“主动感知”提升到了推理策略层。它不是让模型被动吞下整段长视频或多模态输入，而是让系统先决定去哪里找信息、再围绕线索做推理，这有点像把检索、观察和思考串成一个闭环。公开页面强调，即便是较小模型，也能在这种框架下获得更高的信息提取效率和更好的长视频理解表现。这个方向很重要，因为安防、工业巡检、车载视频和长时直播场景都面临同一难题：信息量太大，不可能每一帧都精读。未来多模态智能体的能力上限，很可能不只取决于模型多大，还取决于它是否知道什么时候该看、该跳、该追踪什么。

AI锐评：长视频理解不该靠蛮力硬读，应该像人一样先扫一眼、抓重点、再回看。会“挑着看”的模型，才有资格谈规模化部署。

🔗 https://huggingface.co/papers/2606.19341

🔓 开源热榜

Superpowers 把“技能框架”做成编码智能体工作流，目标不是补插件，而是重写开发方法论

GitHub 上的 superpowers 项目这两天热度很高，它不是单独解决某个 IDE 痛点，而是试图把 coding agent 的完整开发流程标准化。项目说明里把链路拉得很长：先用 brainstorming 提炼需求，再用 writing-plans 拆成 2 到 5 分钟粒度的小任务，接着用 subagent-driven-development 或执行计划去跑实现，中间强制穿插 TDD、代码审查和收尾验证。它支持 Claude Code、Codex、Cursor、Gemini CLI、Kimi Code 等多套 agent harness，重点不是让某个模型更聪明，而是让不同智能体都按同一套工程纪律干活。这意味着开源社区的竞争，正在从“谁家模型更强”转到“谁能把 agent 工程化工作流打包得更顺”。

AI锐评：单个模型能力再强，没流程也只像天赋型实习生。Superpowers 真正卖的不是插件，是把 coding agent 变成可管理工程团队的幻觉。

🔗 https://github.com/obra/superpowers

Continue 继续巩固多模型编程入口，开源阵营开始和闭源 IDE 正面拼工作流

Continue 作为开源编程助手项目仍在持续吸引开发者，核心吸引力在于它把多模型接入、编辑器集成和可自定义工作流放在一个统一入口。相比把开发者锁进单一商业 IDE，它更像一个“可替换模型、可替换后端、可延展工具链”的开放控制台。公开仓库展示的方向已经不只是聊天补全，而是朝着完整 coding agent 演化：模型选择、上下文注入、调试辅助、代码修改和团队级配置都能集中管理。这个趋势说明，开源编程助手现在的价值不只在省钱，还在于给企业留下系统主导权。谁要是担心模型供应商切价、断供或改策略，最后多半都会重新考虑这种开源入口。

AI锐评：当闭源工具开始涨价、限速、分层收费，开源入口的意义就不是“能不能用”，而是“最后谁掌握控制权”。Continue 吃到的正是这股情绪红利。

🔗 https://github.com/continuedev/continue
