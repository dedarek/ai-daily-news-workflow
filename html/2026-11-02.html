美团发布LongCat-2.5模型，GDPx评测显示顶尖模型专业任务得分仅12%

美团发布原生多模态模型LongCat-2.5，总参数达1.6万亿，每个Token激活约480亿参数，重点强化视觉理解与长程智能体编程能力。同期发布的GDPx基准测试覆盖芯片、法律、金融等11个专业领域，结果显示当前最佳模型在真实专业任务中仅获得12%的得分，暴露出通用智能体在垂直领域的能力缺口。此外，Apple Intelligence国行版据称将于12月接入千问模型，但尚待官方确认。

AI锐评：LongCat-2.5通过稀疏激活架构平衡了规模与效率，但GDPx基准的低分表明，大模型在复杂专业场景下的落地仍面临显著的能力瓶颈，通用智能体距离真正替代专家尚有距离。

🚀 产品发布

DeepSeek开源dsh-superagent编码智能体，采用路由-工作者架构提升并行效率

DeepSeek Harness团队以MIT协议开源了dsh-superagent，这是一个针对GitHub仓库的主动式编码智能体研究原型。该系统采用路由-工作者（Router-Worker）双层架构，将请求拆分为并行工作项，每个任务在独立会话中执行。在官方模拟测试中，其任务完成时间的p95从单会话基线的29.5分钟降低至15.7分钟。该原型支持监听GitHub和飞书事件，旨在通过减少人工注意力瓶颈来提升研发流程自动化效率。

AI锐评：该架构通过并行拆分任务有效缓解了单会话智能体的注意力瓶颈，但当前测试仅基于模拟环境，其在真实复杂代码库中的稳定性与代码质量仍需进一步验证。

🔗 https://www.marktechpost.com/2026/11/01/deepseek-dsh-superagent-router-worker-coding-agent/

Nace AI开源27B多模态决策模型Drex Max v1，支持Apple Silicon本地运行

Nace AI开源了Drex Max v1，这是一款27B参数的密集多模态决策模型，支持262,144 token上下文窗口。该模型主打本地部署，提供bf16、Q8_0 GGUF及affine Q4等多种量化版本，可在配备24GB以上内存的Apple Silicon Mac上运行。在公开评测中，其Decision Index 0.4得分为67.52，较前代模型提升6.27分。该模型通过单次前向传播输出选项概率，适用于智能体路由、工单分类及策略检查等场景。

AI锐评：Drex Max v1将中等规模多模态模型的部署门槛降至消费级硬件，为对数据隐私有严格要求的场景提供了私有化验证方案，但其决策能力主要依赖特定评测集，通用推理能力有待更多第三方基准检验。

🔗 https://www.marktechpost.com/2026/11/01/nace-ai-open-sources-drex-max-v1-local-inference/

💼 行业动态

Parameter Labs披露ChatGPT账号接管漏洞，利用沙箱iframe缺陷窃取用户数据

Parameter Labs披露了一条针对ChatGPT的完整攻击链，利用其Artifacts（现称HTML previews）功能在沙箱iframe中渲染自定义HTML时的实现缺陷。攻击者通过MathLive库的postMessage机制向父页面注入HTML，进而利用YouTube oEmbed端点反射执行JavaScript，最终绕过CSP限制。一旦获得执行权限，攻击者可访问OpenAI内部API，窃取用户私有数据或代表用户执行操作。OpenAI已修复该漏洞并支付5,000美元赏金。

AI锐评：该漏洞揭示了AI生成内容渲染沙箱中隔离机制的脆弱性，表明只要允许不可信代码在浏览器环境运行，严格的权限控制与跨域策略设计是防止数据泄露的关键防线。

🔗 https://simonwillison.net/2026/Oct/31/how-we-took-over-chatgpt-accounts/

Agent Sandbox 成为新算力形态：海量轻量执行需求重塑基础设施

随着 Agent 每日创建量达到上千万次，每次运行都需要拉起可执行、隔离且可回收的环境，算力需求正从训练转向海量轻量执行。沙箱的启动时延、部署密度及隔离成本直接决定了 Agent 平台的用户体验与毛利空间。因此，沙箱基础设施需作为一等公民进行设计，以应对高频次、短生命周期的执行挑战。

AI锐评：Agent 基础设施竞争焦点正从模型能力转向沙箱的工程效率，启动速度与隔离成本将成为平台盈利的关键变量。

💡 前沿研究

清华姚期智团队提出代数世界模型，通过形式化证明提升 AI 推理准确性

清华大学姚期智和袁洋团队提出“代数世界模型”（AWM），旨在让 AI 从观测数据中归纳出可解释的代数结构，而非仅拟合现象。在 ARC-AGI-3 测试中，AWM 能准确判断无解关卡并给出证明，而现有顶级模型常出现幻觉。该模型在全部 183 个关卡中通关，平均动作数仅为人类基准的 43%，展示了符号归纳在科学发现路径上的潜力。

AI锐评：AWM 通过引入形式化证明解决了纯神经网络在反事实推理中的幻觉问题，但受限于观测完整性，其结论仅反映局部真理。

🔗 https://www.qbitai.com/2026/11/507031.html

研究揭示 MCP 与 CLI 接口差异显著影响 Agent 行为与成本

一项受控研究比较了 MCP 与 CLI 两种接口在能力对齐下的表现，发现接口表征显著改变了 Agent 的任务成功率与交互成本。在 2004 个交互片段中，94.3% 显示出结构化分歧，早期差异会传播至后续交互。提出的 DART 方法通过修复接口特有的实现细节，在六个评估场景中提升了最高 9.0 分的基准得分，并降低了 MCP 的 Token 消耗。

AI锐评：接口语义与呈现方式本身是 Agent 决策环境的一部分，优化接口实现能直接提升性能并降低推理成本。

🔗 https://arxiv.org/abs/2610.34298

WorkFactory 框架通过结构化任务生成提升长程 Agent 训练效果

WorkFactory 框架通过从专业意图构建信息支持图，并执行探测与修复机制，批量生成连贯且可执行的专业任务。基于 112,686 个任务训练的 WorkPilot 系列模型在多个基准上超越基座模型，其中 35B-A3B 版本在 GDPval-AA v2.1 上的 Elo 分数从 879 提升至 1565。分析表明，任务构造的质量比轨迹数量更能决定长程 Agent 的性能上限。

AI锐评：该工作证明高质量的任务结构优于单纯的数据规模，解决了合成数据中常见的依赖缺失与一致性问题。

🔗 https://arxiv.org/abs/2610.37161

vLLM 发布 v0.33.0 版本

vLLM 项目于 11 月 1 日发布了 v0.33.0 版本，该版本由 khluu 标记。虽然页面未直接列出详细变更日志，但作为主流推理引擎，该版本通常涉及调度机制、算子优化或新硬件后端的适配。对于自建推理服务的团队，建议在升级前仔细核对新版本与现有模型架构、量化格式及 CUDA 版本的兼容性，以避免潜在的运行错误。

AI锐评：版本迭代本身不直接改变性能上限，但兼容性验证是生产环境升级的关键门槛，盲目跟进可能导致服务中断。

🔗 https://github.com/vllm-project/vllm/releases/tag/v0.33.0

llama.cpp b12031 增强 OpenCL 后端 IQ3 量化支持

llama.cpp 发布预发布版本 b12031，重点为 OpenCL 后端添加了初版 IQ3 量化支持。该更新覆盖了 AOS/SOA 内存布局、tiled matmul 以及针对高通 Adreno GPU 的无洗牌 GEMM/GEMV 和 dp4a 路径优化。此外，版本还针对解码和小批量场景进行了性能调优，并提供了包括 Windows arm64 OpenCL Adreno 在内的多种平台构建包。

AI锐评：针对 Adreno GPU 的低比特量化优化降低了移动端本地推理的门槛，但预发布状态意味着稳定性仍需在实际部署中验证。

🔗 https://github.com/ggml-org/llama.cpp/releases/tag/b12031

🤖 Agent & 工具

Arca 分享长周期金融 Agent 工程化实践

Arca AI 负责人 Aman Singh 介绍了该公司在财富管理领域应用 Agent 的经验。Arca 构建了内部持久记忆系统和自研 harness，以支持跨越数天、涉及多次人工交接的长周期任务。系统使用 Anthropic 和 OpenAI 的模型，并通过内部基准自动选择最佳模型。在安全方面，Agent 仅负责分析和提案，所有资金交易等高风险操作均由人类顾问执行，且安全限制完全基于确定性规则。

AI锐评：自研 harness 和确定性安全护栏解决了长程任务中的记忆断层与合规风险，证明了工程编排比单纯依赖大模型能力更关键。

🔗 https://latent.space/p/arca/

Adobe 推出 EditAgent 提升图像编辑精度

Adobe Research 与 UCSD 合作开发了 EditAgent 系统，旨在模拟专业 Photoshop 用户的操作逻辑。该系统将编辑任务分解为子步骤，并行生成通用编辑器和专用工具的多种结果，并由语言模型基于亮度、色彩等实测统计数据进行评估。在 600 项编辑测试中，EditAgent 的精度优于现有方案，但计算成本约为传统方法的十倍。

AI锐评：以十倍算力换取更高精度的策略适合离线高质量场景，但高昂的计算成本限制了其在实时交互应用中的落地可能性。

🔗 https://the-decoder.com/adobe-is-testing-how-well-ai-agents-can-use-editing-tools-like-a-photoshop-professional-would/
