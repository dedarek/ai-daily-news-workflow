Black Forest Labs发布FLUX 3，统一多模态生成与机器人控制

Black Forest Labs推出了FLUX 3，这是该系列首个利用单一架构和同一组权重同时支持图像、视频、音频生成及机器人动作预测的多模态流模型。该模型基于Self-Flow方法，通过联合训练让不同模态相互约束，确保声音与物理撞击匹配、运动符合质量规律，从而更完整地描述现实世界。在视频生成方面，FLUX 3可单次生成长达20秒且带有原生音频的片段，在人类偏好测试中，其表现显著优于Luma Ray 3.2和Runway Gen-4.5等竞品。此外，该模型还驱动了FLUX-mimic机器人策略，能在单张RTX 5090显卡上实现低于80毫秒的推理速度，目前视频和动作功能已进入早期访问阶段。

AI锐评：FLUX 3通过统一架构打破了模态壁垒，将生成式AI从单纯的内容创作延伸至具身智能控制，但早期访问的分级策略可能限制其生态的快速普及。

🔗 https://www.marktechpost.com/2026/07/26/black-forest-labs-releases-flux-3-a-multimodal-flow-model-for-image-video-audio-and-robot-action-prediction/

NVIDIA Nemotron 3 Ultra在智能体RTL编码任务中领跑开源模型

NVIDIA发布了Nemotron 3 Ultra，该模型结合ACE-RTL智能体，在智能体驱动的寄存器传输级（RTL）编码任务中实现了准确率与效率的双重突破。在综合Verilog设计问题基准测试中，Nemotron 3 Ultra配合智能体工作流在九类任务中的平均通过率高达97.1%，远超GLM 5.2和Kimi K2.6等模型，且每次迭代消耗的Token数量减少了71%。其采用的混合Mamba-Attention混合专家架构，配合经过严格筛选的合成RTL数据集训练，使其具备长上下文推理能力，能有效处理芯片设计中的复杂调试与验证工作。这一进展为芯片设计公司提供了减少人工编写代码耗时的新方案，并展示了与Cadence、Synopsys等主流EDA工具集成的潜力。

AI锐评：Nemotron 3 Ultra证明了垂直领域专用模型在工程化场景下的巨大价值，但其高度依赖特定智能体工作流可能限制了独立模型的直接可用性。

🔗 https://developer.nvidia.com/blog/nvidia-nemotron-3-ultra-leads-open-models-on-accuracy-and-efficiency-in-agentic-rtl-coding/

AI锐评：NVIDIA的重注表明算力已成为安全AI研究的核心瓶颈，但SSI完全摒弃商业化路径的激进策略在长期资金可持续性上仍面临考验。

DeepSeek叫停第二轮融资签约

DeepSeek已口头通知部分潜在投资方，原计划在未来几天签署的第二轮融资协议将暂缓执行。该轮融资原计划募资至少100亿元，投前估值不低于4800亿元。暂停的直接诱因是几天前一份据称内部交流备忘录的泄露，引发了管理层对信息安全的担忧。尽管签约被叫停，但融资并未正式终止，未来仍可能重启交易流程。此次暂停发生在公司完成首轮外部融资仅数周之后，显示出其在资本市场的持续活跃与潜在风险并存。

AI锐评：融资暂停暴露了DeepSeek在高速扩张期对内部信息管控的脆弱性，可能影响后续IPO估值锚定及股东信任构建。

AMD发布全球首款2nm GPU并获巨头订单

AMD在Advancing AI 2026大会上发布了基于台积电2nm工艺的MI455X GPU及Zen 6架构CPU，共同构成Helios机架级AI系统。该系统已于2026年第三季度末进入量产阶段，OpenAI、Meta、微软和甲骨文等巨头已签署协议并规划大规模部署。MI455X采用Chiplet设计，其中计算芯粒使用2nm工艺，总晶体管数约3200亿，并配备432GB HBM4显存。AMD试图通过开放互连标准和系统级交付方案，挑战英伟达在高端AI芯片领域的垄断地位。

💡 前沿研究

Skill Self-Play提出LLM技能自博弈新框架

针对现有自进化方法在任务多样性与验证可靠性之间的困境，研究者提出了“技能自博弈”框架。该框架包含提议者、求解者和动态技能控制器三个组件，通过强化学习循环实现共同进化。提议者基于动态采样的技能生成挑战性任务，求解者探索解决方案，技能控制器则收集反馈以更新技能库。实验表明，该方法在工具使用和推理基准测试中能有效提升模型性能上限，并帮助初始对齐不佳的模型实现显著逆转。

AI锐评：该框架通过可验证的中间技能作为锚点，有效解决了开放生成训练中的奖励污染问题，为LLM能力边界拓展提供了更稳定的训练路径。

🔗 https://arxiv.org/abs/2607.22529

原生多模态预训练缩放规律研究取得突破

纯文本预训练限制了大模型对物理世界的感知，而原生多模态预训练能从输入端深度融合图文模态。研究团队通过大规模实验首次系统揭示了该范式随参数、数据与计算量变化的缩放行为。研究发现，最小目标损失遵循可预测的计算定律，而计算最优的模型规模和令牌数则呈幂律缩放。此外，语言目标与多模态目标表现出不同的缩放特性，文本密集型混合数据仅在更大模型规模下才具备计算效率。

AI锐评：该研究明确了原生多模态预训练的资源分配法则，指出文本数据比例对模型规模敏感，为构建高效多模态基座提供了量化依据。

🔗 https://arxiv.org/abs/2607.22043

Molt: 纯 PyTorch 原生智能体强化学习训练框架

Molt 是一个专为智能体强化学习设计的纯 PyTorch 原生训练框架，旨在解决算法频繁变更带来的工程复杂性。该框架将训练器、分布式后端与 rollout 胶水代码封装得极为简洁，使研究人员甚至 AI 编程助手都能轻松阅读和修改整个代码库。其核心设计确保智能体作为普通程序运行，通过异步循环训练多模态及混合专家策略，且严格保证不训练未生成的 token。在性能方面，Molt 在完全异步协议下与基于 Megatron 的先进方案统计相当，同时提供了开源代码、配方及容器以支持快速迭代。

AI锐评：Molt 通过极简架构降低了智能体研究的工程门槛，证明了轻量化设计未必牺牲性能，为快速验证新算法提供了高效工具。

🔗 https://arxiv.org/abs/2607.21653

🔓 开源热榜

llama.cpp b10152 优化多 Token 预测 GPU 层分配

llama.cpp 发布了 b10152 版本，重点改进了多 Token 预测（MTP）机制下的 GPU 层分配逻辑。此次更新确保前置层始终驻留在 GPU 显存中，有效减少了 CPU 与 GPU 之间的数据搬运开销。这一优化直接提升了大模型在推理阶段的预测效率，降低了延迟。该版本支持多种硬件平台，包括 NVIDIA CUDA、AMD ROCm 以及 Apple Silicon 等，并提供了详细的构建资产供开发者下载。

AI锐评：针对 MTP 场景的显存调度优化，直接解决了数据搬运瓶颈，显著提升了推理吞吐，是端侧部署的重要性能增益。

🔗 https://github.com/ggml-org/llama.cpp/releases/tag/b10152

vLLM v0.26.0 全栈支持 Inkling 模型并优化 DeepSeek-V4

vLLM 发布 v0.26.0 版本，新增了对 Inkling 模型族的全栈支持，涵盖基础建模、投机解码、LoRA 微调及 NVFP4 量化。针对 DeepSeek-V4 模型，该版本推出了定制路由内核与融合算子，在多个 GPU 厂商硬件上显著改善了端到端延迟。此外，更新还增强了注意力后端灵活性，支持按 KV 缓存组选择后端，并大幅完善了 KV 卸载与分层二级存储机制。Rust 前端也扩展了对多模态视频和音频的支持，进一步提升了系统的通用性。

AI锐评：对特定模型架构的深度定制优化，展示了推理引擎在适配新兴模型时的敏捷性，能有效释放异构硬件的计算潜力。

🔗 https://github.com/vllm-project/vllm/releases/tag/v0.26.0

🤖 Agent & 工具

Cursor 智能体集群凭手册重造 SQLite 验证编排价值

Cursor 工程团队利用智能体集群，仅凭 835 页 SQLite 参考手册，在无源码、无测试用例且不联网的条件下，用 Rust 成功重写了完整的数据库引擎。实验对比显示，采用规划者与执行者分工的混合模型方案，成本仅为全用前沿模型的八分之一，且代码量更少、冲突更少。该成果通过了预留的 sqllogictest 测试集，证明了智能体在复杂软件再实现上的能力。研究指出，智能体的编排策略与上下文隔离机制比单纯提升模型能力更能决定最终产出效率。

AI锐评：该实验揭示了多智能体协作中“编排优于模型”的核心规律，表明通过合理的任务拆解与上下文管理，低成本模型组合可完成高复杂度工程任务。

🔗 https://www.infoq.cn/article/5qw8Qe37kGVDq9Yy57XC?utm_source=rss&utm_medium=article
