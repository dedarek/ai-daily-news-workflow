微软发布七款自研模型，旨在以更低成本替换外部AI服务

微软在Ignite大会上一次性发布了包括代码、安全、图像、语音及路由在内的七款自研模型，明确意图用更便宜的自有模型替换产品线中的外部模型。其中，MAI Code 2在内部基准测试中达到GPT-6.1 Sol约98%的性能，但成本仅为后者的40%；MAI Cyber 2 Flash在漏洞测试中略胜GPT-6 Astra，且单任务成本极低。这些模型专为全天候运行的企业智能体设计，旨在降低Token消耗带来的运营成本。

AI锐评：微软通过自研模型直接对标OpenAI和Anthropic，利用价格优势重塑企业级AI服务的成本结构，这将进一步压低闭源模型API的市场价格锚点。

🚀 产品发布

vLLM v0.34.0发布：默认启用可扩展KV缓存并移除V1运行器

vLLM v0.34.0版本合并了1061个提交，新增10个模型支持。该版本默认开启可扩展KV缓存，根据预热后实际空闲显存自动定容，建议用户移除配置中的gpu_memory_utilization参数以获取更高吞吐。同时，Model Runner V1被正式移除，V2成为唯一GPU运行器，并在Blackwell和MI355X硬件上实现了显著加速，如Step5解码速度提升1.95倍。

AI锐评：默认启用可扩展KV缓存并移除旧版运行器，标志着vLLM在资源利用效率上的重大优化，但配置变更可能导致现有部署出现兼容性问题，需仔细检查升级指南。

🔗 https://github.com/vllm-project/vllm/releases/tag/v0.34.0

Google DeepMind推出Genie 4，支持实时文本修改与社区再创作

Google DeepMind更新了Project Genie，向Google AI Ultra订阅用户开放Genie 4世界模型。Genie 4允许用户通过文本实时修改3D世界的天气、角色或剧情，并首次生成适配场景的原生实时音效。此外，旧版Genie 3也获得更新，支持长达3分钟的会话、360度全景及可链接世界，并上线社区画廊供用户分享和再创作，所有内容均带有SynthID水印。

AI锐评：Genie 4从研究预览转向可订阅产品，通过实时交互和音效生成提升了世界模型的沉浸感，社区画廊的引入则试图构建围绕生成式3D内容的创作者生态。

🔗 https://the-decoder.com/google-deepminds-project-genie-update-brings-genie-4-chainable-worlds-and-a-community-gallery-for-remixing/

可灵发布 Kling Image 4.0，支持原生 8K 生成与长指令处理

AI锐评：Kling Image 4.0 将竞争焦点从风格化转向分辨率与细节一致性，更贴近印刷、电商等真实生产需求。其长指令与组图能力表明，图像模型正从单点生成向复杂工作流执行演进。

范式智能发布Phai系列模型，基于华为昇腾全链路训练

范式智能发布Phai-A1和Phai-M1两款模型，均基于华为昇腾平台完成全链路训练。Phai-A1为通用语言模型，单张RTX 3090即可运行，响应速度比同参数模型快8-10倍，支持原生百万级上下文；Phai-M1面向真人影视场景，约3分钟可生成15秒720P音画同步视频。官方称两款模型近期将在Hugging Face和ModelScope开放权重，旨在验证国产算力在模型训练中的可行性。

AI锐评：范式通过“小模型+国产算力”策略切入基模市场，Phai-A1的低部署门槛和高速响应针对特定效率场景，而全链路昇腾训练则强化了其在国产AI生态中的技术绑定优势。

腾讯混元 Hy4 flash 上线首日登顶 OpenRouter，主打极致低成本

腾讯混元发布的轻量级多模态模型 Hy4 flash 在 OpenRouter 上线首日即登顶热度榜，Token 调用量突破 50 万亿。该模型总参数量 224B，激活参数仅 12B，支持 1M 上下文，输入价格低至 0.5 元/百万 Token，单任务成本约 0.26 元，仅为 Hy4 preview 的 1/13。内部盲测显示，其用户满意度接近 Claude Haiku 5.5，但成本仅为后者的 1/18，且任务耗时更短。

AI锐评：Hy4 flash 以极低的推理成本切入市场，直接压缩了高频调用场景的边际成本。其竞争力在于通过架构优化平衡了性能与价格，迫使竞争对手在性价比维度重新定价。

🔓 开源热榜

PEFT v0.22.0 发布：引入 PaCA 方法与 LoRA 初始化改进

Hugging Face 发布 PEFT v0.22.0，新增 ICLR 2025 提出的 PaCA（部分连接适配）方法。PaCA 通过微调预训练权重中随机选定的输入列，而非叠加 adapter 层，从而消除串行计算并减少反向传播时的激活保存。官方数据显示，相比 LoRA，PaCA 训练时间减少 22%，显存占用降低 16%，且支持更长的序列长度。此外，该版本还引入了 Astra 和 NoRA 两种新的 LoRA 初始化策略，并增强了对张量并行（TP）和 FSDP2 的支持。

AI锐评：PaCA 在显存和速度上的优势对资源受限场景极具吸引力，但其仅支持 nn.Linear 层且在小批量或轻量模块上效果受限，适用性需具体评估。

🔗 https://github.com/huggingface/peft/releases/tag/v0.22.0

Unsloth 更新：强化 AMD NPU 支持并新增视频扩散 LoRA 训练

Unsloth 发布 v0.1.920-beta 版本，显著增强了 AMD NPU 支持，用户转换的 Q4NX 模型可直接在 NPU 上加载，且每个模型均标注运行状态。官方称 NPU 在每焦耳每 token 的效率上比 GPU 高 2 到 4 倍。该版本还新增了 LTX-2.5 和 MOSS-Image 的 LoRA 训练功能，以及 NVIDIA Cosmos3 的 FP8 视频模型支持。在 Strix Halo 平台上，FLUX.3 Klein 的单步推理速度最高提升 28%。

AI锐评：NPU 能效优势明显，但当前仅支持文本加载且依赖特定硬件，视频扩散 LoRA 的加入则进一步降低了本地微调门槛。

🔗 https://github.com/unslothai/unsloth/releases/tag/v0.1.920-beta

Hugging Face 发布 Qwen3.8-27B-pi-adapted LoRA 适配器

Hugging Face 的 harness-hub 团队发布了 Qwen3.8-27B-pi-adapted，这是一个针对 pi 编码智能体训练的 LoRA 适配器。该适配器采用 AsyncGRPO 强化学习算法，在 SWE-bench Pro (hard-51) 上将 pass@1 从 39.2% 提升至 64.7%，在 Terminal-Bench 2.1 上从 39.5% 提升至 55.8%。相比基座模型开启思考模式，该适配器在保持同等精度的同时，生成的 token 数量减少约 4.5 倍，显著提升了推理效率。

AI锐评：小体量 RL 适配器在特定智能体场景下能大幅降低推理成本，但基准测试规模较小且仅限 pi 环境，泛化能力有待验证。

🔗 https://www.marktechpost.com/2026/11/18/hugging-face-qwen3-8-27b-pi-adapted-lora/
